# Shared FedVaDE checkpoint evaluation

A_author: author CSV, first 31 columns including A1 ID, last column labels; StandardScaler fitted on all 569 CSV rows before the author's seeded non-IID client partition (seed 42). Evaluate concatenated 10 client loaders (2129 records, duplicates weighted), batch size 200, shuffle=True, CPU float32. For each independent evaluation seed 0..9, reset torch RNG, call unmodified VaDE.predict (sample z from encoder Gaussian, GMM posterior argmax), then unmodified experiment.validation (labelMapping, Purity, ARI). These are ten inference draws of each fixed checkpoint, NOT ten training seeds. Labels enter metrics only during evaluation; author training uses labels in partition and local GMM component-count initialization. The author checkpoint may have unknown training scaler/feature/partition provenance.

B_unique_diagnostic: same CSV, columns, all-data StandardScaler, checkpoint, VaDE.predict and metrics, but evaluate each of 569 CSV rows exactly once in original order, batch size 200, shuffle=False. This isolates evaluation duplicate weighting, but does not remove label-assisted training or all-data scaler exposure; it is NOT an independent held-out generalization test.
