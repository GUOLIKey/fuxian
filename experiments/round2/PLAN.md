# 第二轮聚类诊断

- A：Fed-HIRE Iris，学习率 0.0001、0.03、0.05，各用种子 0、1；一次调用作者聚类函数，不隐藏重试。只在副本中为未显式设种子的服务端 MCPL 和最终集成设置配对随机流，保留原有显式种子 42。
- B：FedVaDE Breast Cancer，固定种子 0，同设备分别重训 50+300 轮。A 组保留每 batch 调用客户端 StepLR；B 组仅将客户端 StepLR 移到每轮每客户端最后一个 batch 之后。服务端调度不变。记录优化器用于每批更新的学习率和轮末学习率。
- C：FedHCA Ecoli，仅一次正式运行；使用发布入口解析出的默认学习率和聚类比例，固定种子 0 以记录随机状态，不改初始化和评估函数。
- GPU 门槛：固定数据、参数与重参数噪声，比较客户端和服务端损失、编码输出、梯度与更新后参数；另用 3+12 轮短跑检查整条 GPU 路径、有限值及时间。正式训练不启用固定噪声补丁。若门槛不通过，两组 B 使用同一 CPU 环境。
- 预算：8 小时内不超过 9 次正式尝试；截止前只启动预计来得及的任务，已经开始的任务保留。短测与正式记录分开，不重复运行来替换失败结果。VaDE 不训练。
- 证据：每次运行保存命令、源码 diff、分区签名、日志、指标；FedVaDE 保存最终 checkpoint，不按测试指标挑选轮次。
